# Imagens do HANAMI Journal

As oito pastas possuem editorial.svg: ilustrações locais de apoio, sem representar produtos reais. Substitua por fotografias aprovadas quando disponíveis.

Nos artigos, use heroImage: "/images/blog/figo/nome-da-foto.webp" e heroImageAlt com descrição objetiva. Também é possível usar uma imagem local relativa ao Markdown, processada pelo Astro.

Não use fotografias de terceiros sem autorização. Sem heroImage, o layout exibe a ilustração da categoria ou fragrância com alt vazio, por ser decorativa.

As ilustrações e a imagem de compartilhamento são reproduzíveis por node scripts/generate-brand-assets.mjs.
